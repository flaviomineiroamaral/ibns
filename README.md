# Igreja Batista Nacional Shamah (IBNS)

Website da Igreja Batista Nacional Shamah - Uma comunidade de fé e espiritualidade.

## 📋 Conteúdo

- `index.html` - Página principal
- `styles.css` - Estilos da página
- `script.js` - Scripts de interatividade
- `vercel.json` - Configuração para Vercel

## 🚀 Deploy no Vercel

### Opção 1: Deploy Automático (Recomendado)

1. Acesse [Vercel.com](https://vercel.com)
2. Clique em "Add New..." → "Project"
3. Selecione o repositório `flaviomineiroamaral/ibns`
4. Clique em "Import"
5. Vercel detectará automaticamente a estrutura
6. Clique em "Deploy"

Pronto! Sua página estará disponível em um URL como: `ibns-xxxxx.vercel.app`

### Opção 2: Deploy via CLI

```bash
# Instale o Vercel CLI
npm install -g vercel

# Faça login
vercel login

# Deploy
vercel
```
